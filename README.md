# Game Repo

An application for organising a personal video game library: audit ROM sets against
`.dat` files, build and export curated collections, import PC games into a common
structure, and scrape metadata and media for everything.

**Start with the plan: [PLAN.md](PLAN.md).** It describes the goals, feature modules,
architecture, proposed tech stack, milestones, and the decisions still open.

## Status

Planning. No code yet.
